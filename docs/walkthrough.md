# Walkthrough script (about 3 minutes)

A silent version is at [walkthrough.gif](walkthrough.gif). Use this outline to record a narrated one from the demo.

| Screen | Do | Say |
|-|-|-|
| Banner | Point at it | "Made-up materials and students; AI replies are prerecorded; the page can't make network calls." |
| 1 · Import a worksheet | Click **Import worksheet**, then change a point value and import again | "The teacher already had worksheets in Google Docs. A parser turns them into an interactive worksheet and a hidden answer key, with no AI needed." |
| 2 · Formative assessment | **Generate**, change a correct answer, delete the off-topic question, **Release** | "AI drafts from her lesson list. Code throws out malformed questions and saves the draft hidden. She decides what students see." |
| 3 · AI scoring + review | Show Ava (posted), then Leo (flagged); adjust a score; **Approve** | "Scored against her model answers with partial credit. When the model isn't confident, the work goes to her instead of the gradebook. That threshold is on the model's own estimate, not a measured accuracy." |

Screens can be reproduced with `?scene=import|cfa|grade|review`.
